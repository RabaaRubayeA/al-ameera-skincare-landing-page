# Al Ameera | الأميرة 🌸

An Arabic landing page showcasing skincare and beauty products, designed with a right-to-left (RTL) layout.

## 🌐 Live Demo

[Visit Al Ameera Website](https://al-ameera.netlify.app/)

## 📌 About the Project

Al Ameera is an Arabic skincare products landing page created to present beauty products through an organized and visually appealing interface.

The project is part of my frontend development portfolio and demonstrates my ability to build landing pages for businesses targeting Arabic-speaking customers.

## ✨ Features

* Arabic user interface.
* Right-to-left (RTL) layout.
* Skincare and beauty product showcase.
* Responsive layout for different screen sizes.
* Clear product presentation and navigation.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 Project Purpose

* Practice and demonstrate frontend development skills.
* Build a portfolio project for landing page development.
* Create a sample website for Arabic skincare and beauty businesses.
